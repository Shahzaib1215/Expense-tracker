# Expense-tracker
Kharcha Tracker — Pakistan ke liye bana personal kharcha tracker. Bank ka har SMS aur banking app ki har notification khud parh kar paise aane-jaane ka hisaab rakhta hai — Meezan, UBL, HBL, Easypaisa, JazzCash, NayaPay, SadaPay aur aur bhi banks supported. Cash kharcha 5 second me manually add karo. Khaas baatein: 💰 Apna balance khud set karo.
